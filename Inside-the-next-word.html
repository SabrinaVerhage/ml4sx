THE MAP IS NOT THE MACHINE

A useful simplification.

This guide explains a typical autoregressive, decoder-only transformer: the kind of language model that generates text one token at a time.

All token splits, vectors, probabilities and attention patterns here are small, authored examples. They are not measurements from a trained model. The attention playground computes real scaled dot products, a causal mask, softmax and weighted sums using toy vectors.

The moving field is a visual metaphor, not a plot of a model’s actual semantic space. Attention weights describe one information-mixing operation; they are not a complete explanation of a model’s reasoning or behaviour.

Training learns parameters. Attention uses those parameters to calculate context-dependent connections. Alignment is a separate goal and set of methods for shaping behaviour; it does not mean geometrically lining up word vectors.
